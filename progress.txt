## Codebase Patterns
- Routes are auto-discovered by server.ts via glob `dist/src/slices/**/routes{,-*}.js` — no manual route registration needed (skip skill's "wire up the route" step for this project).
- Context directory names under `src/slices/` follow the same lowercase-no-spaces convention as slice folders in index.json (e.g. context "Todo List" -> `src/slices/todolist/`).
- Root project has its own `package.json`/`node_modules`, separate from `.build-kit/node_modules` — run `npm install` at repo root before `npm run build`/tests.
- No `.git` repository existed at project start; initialized with `main` as the default branch and a `node_modules/`, `dist/`, `.env` entries added to `.gitignore` before the first commit.
- `.build-kit/.eventmodelers/config.json` is absent in this project, so per the Ralph "Important" note, all platform/board communication (update-slice-status, MCP) is skipped — work stays local only.
